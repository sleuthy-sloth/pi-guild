# UI Design

Guidance for producing deliberate, polished interfaces.

## Principles

- Typography: one clear hierarchy, consistent scale, readable line lengths.
- Spacing: consistent rhythm; use a spacing scale rather than ad-hoc values.
- Color: a restrained palette with enough contrast for accessibility (WCAG AA).
- States: hover, focus, active, disabled, and empty states are not optional.

## Workflow

1. Read the existing styles/components before adding new ones.
2. Reuse existing patterns; don't introduce a parallel style system.
3. Make the change visually complete — no unstyled defaults.
4. Verify contrast and spacing after editing.
